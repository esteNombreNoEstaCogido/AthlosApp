# Reglas de Eficiencia de Tokens
- Sé extremadamente conciso. Evita introducciones, explicaciones obvias o cortesías.
- Devuelve **únicamente** las líneas de código modificadas o el bloque específico que responde a la pregunta. No reescribas archivos enteros si solo cambia una función.
- Si detectas código repetitivo, usa pseudocódigo o comentarios de marcador de posición (ej: `// ... resto del código igual ...`).
- Prioriza soluciones que utilicen herramientas nativas para no sobrecargar el contexto.
